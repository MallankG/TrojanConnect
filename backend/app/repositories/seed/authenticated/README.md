# Authenticated Seed Data (EngageSC)

**Collection Date**: 2026-11-14

## Privacy and Access Notice

This dataset was collected from EngageSC pages that require an authenticated USC NetID login. 

- **CONFIDENTIALITY**: This data came from pages behind a USC NetID login.
- **RESTRICTION**: It must not be published, deployed in a public demo, or shared outside the team.
- **DATA MINIMIZATION**: In accordance with privacy rules:
  - No individual-person data (no officer names, photos, personal emails, phone numbers, or individual profile links) has been recorded.
  - Only aggregate counts (member count, officer count, event count) and shared organizational contact channels (official org email, org website, org social handles) are collected.
  - All USC institutional default accounts (e.g. `instagram.com/uscedu`, `facebook.com/usc`, `twitter.com/usc`, `linkedin.com/school/3084`, `youtube.com/user/USC`) have been excluded.
  - Recruitment status is recorded strictly when explicitly indicated ("open", "application", "closed"), otherwise defaulting to "unknown".
