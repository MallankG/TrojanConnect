# TrojanConnect brand marks

All PNG exports use transparent backgrounds and the product palette (`#990000` cardinal, `#FFCC00` gold, black, and white). The mark is an open cardinal “C” joined to a gold connection point, set in a rounded app tile for square use. It avoids USC seals, monograms, and other official university marks.

- `trojanconnect-horizontal.png` — horizontal wordmark, 1560 × 400 px.
- `trojanconnect-square.png` — standalone square mark, 1024 × 1024 px.
- `favicon.png` — 64 × 64 px favicon-ready mark.
- The corresponding SVGs are included as editable source files.
